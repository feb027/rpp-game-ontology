# Brief Tugas Besar RPP

## Mata Kuliah
Representasi Pengetahuan dan Penalaran

## Judul Studi Kasus
Study Case: Sistem Rekomendasi Game Berdasarkan Preferensi dan Mood Menggunakan Ontologi

## Petunjuk Teknis

1. Bentuk kelompok kerja maksimal 4 orang.
2. Setiap kelompok mengerjakan studi kasus berbeda.
3. Pengembangan sistem berbasis pengetahuan:
   - Dikumpulkan saat UAS.
   - Menggunakan Protégé.
   - Berdasarkan kerangka kerja Methontology untuk pengembangan ontologi.

## Rincian Tugas

a. Cara unduh dan instalasi tools  
b. Pengenalan lingkungan kerja tools  
c. Deskripsi persoalan kasus  
d. Deskripsi solusi penyelesaian kasus  
e. Penerapan kasus menggunakan tools  
f. Demo aplikasi

## Format Pengumpulan

- Poin a–e dalam bentuk slide presentasi.
- Poin f dalam bentuk perangkat lunak.
- Semua dikemas menjadi video tutorial.
- Slide presentasi + aplikasi perangkat lunak + video tutorial dikumpulkan ke ketua kelas dan dibagikan ke kelompok lain.
- Video tutorial diunggah pada channel YouTube AIS.

## Scope Awal Sistem

Sistem rekomendasi game berbasis pengetahuan yang memanfaatkan ontologi untuk menghubungkan:

- mood pengguna: santai, kompetitif, stres, bosan, ingin eksplorasi, ingin sosial
- preferensi genre: RPG, puzzle, FPS, simulation, adventure, strategy, casual
- platform: PC, mobile, console
- mode: single-player, multiplayer, co-op
- durasi bermain: singkat, sedang, panjang
- tingkat kesulitan: mudah, sedang, sulit
- output rekomendasi: daftar game + alasan rekomendasi

## Prinsip Solusi

- Ontologi memodelkan kelas, relasi, individu, dan aturan inferensi.
- Reasoning menghasilkan rekomendasi berdasarkan kombinasi mood dan preferensi.
- Demo app menunjukkan input user dan output rekomendasi + alasan berbasis knowledge base.
